# DomLivo — план действий по SEO (аудит 09.09.2026)

Контекст: у проекта уже есть `docs/seo/SEO-ROADMAP-12M.md` — живой 12-месячный роадмап, в котором закрыто SEO-00, 02, 04, 05б, 05в, 06 (шаги 1–4), 06б, 08 и часть 12. Этот план его **не заменяет**. Он говорит, что аудит нашёл сверх роадмапа и что в роадмапе стоит переставить местами.

Главный вывод: **техника сайта не является причиной нуля в органике.** Разметка листингов сильнее, чем у конкурентов, sitemap разложены по типам, noindex расставлен верно, hreflang реципрокен. Причина — возраст, отсутствие ссылочного веса и то, что каталог наполнен чужим импортированным текстом. Поэтому «технический» блок ниже маленький и в основном про заглушки, а тяжёлый — про авторитет и контент.

## Фаза 1 — эта неделя (данные, без которых дальше вслепую)

6. **Подключить Search Console и GA4.** Это блокирует половину плана и стоит в роадмапе как SEO-01, до сих пор `[ ]`. Без GSC нельзя ответить на главный вопрос — что из 1767 URL вообще в индексе. Что нужно от вас — в конце файла.

Однотипна, снимается скриптом по образцу `stripListingEmoji.ts`. Заодно `strip:listing-emoji -- --all` для оставшихся 45. → C4, C5

## Фаза 2 — 2–4 недели (то, что реально сдвинет)

9. **Ссылочное — сейчас это узкое место №1.** 452 ссылающихся домена при DR 0 означают, что профиль состоит из мусора. В роадмапе это SEO-13 (квартал 2) — **перенести в текущий квартал**. Минимум: 10–15 честных ссылок — албанские бизнес-каталоги, профили на порталах недвижимости, экспат-сообщества (Facebook-группы, Reddit r/albania), пара гостевых материалов на invest-in-albania.org и подобных, упоминания в польских и русских релокационных ресурсах. Цель квартала — не 100 ссылок, а 10 живых.

   Калибровка по веб-графу (C14): конкуренты держатся на 1–2 ссылающихся хостах, century21albania.com стоит на 4.5 млн месте по PageRank. Планка низкая — но domlivo в краул Common Crawl не попал вовсе, тогда как все восемь конкурентов попали. Поэтому первая измеримая цель формулируется не как «догнать», а как «попасть в граф»: несколько ссылок с хостов, которые Common Crawl уже краулит. Проверяется бесплатно на следующем релизе графа.
10. **Сущность бренда.** Google не знает, что DomLivo существует: брендовый запрос не возвращает сайт. `RealEstateAgent` вместо `Organization`, с `address`, `areaServed`, `geo`, `openingHours`; Google Business Profile; одинаковый NAP на сайте, в GBP и в каталогах. → C8
11. **Уникальный текст на коммерческих посадочных.** Городские и районные страницы — то, что должно ранжироваться по `shtepi ne shitje durres` (GSV 900, KD 12), `nieruchomości albania` (GSV 400, KD 0), `купить квартиру в албании` (GSV 600, KD 0). Часть текста для Дурреса и 10 прибрежных зон уже написана (SEO-12), нужно закрыть остальные города.
12. **hreflang вторым каналом.** Сейчас он только в HTTP-заголовке. Добавить `xhtml:link` в sitemap — один канал не должен быть единственным на 1767 URL. → C3

## Что нужно от вас, чтобы разблокировать Фазу 1

**Search Console + GA4 (пункт 6).** Я не могу это сделать сам — нужен ваш Google-аккаунт.

1. Google Cloud Console → новый проект → включить API: `Search Console API`, `PageSpeed Insights API`, `Chrome UX Report API`, `Google Analytics Data API`.
2. Создать service account, скачать JSON-ключ.
3. В Search Console (`sc-domain:domlivo.com`) добавить e-mail этого service account как пользователя с правом **Full** (или хотя бы Restricted).
4. Создать API key для PSI/CrUX.
5. Положить файл `~/.config/claude-seo/google-api.json`:
```json
{
  "service_account_path": "C:/путь/к/service_account.json",
  "api_key": "<GOOGLE_API_KEY>",
  "default_property": "sc-domain:domlivo.com",
  "ga4_property_id": "properties/<ID>"
}
```

После этого я добираю то, что сейчас недоступно: реальная индексация по типам страниц, запросы/показы/CTR/позиции, полевые Core Web Vitals из CrUX, органический трафик из GA4 — и дополняю этот план цифрами вместо гипотез.

**Опционально, но сильно помогает:** Bing Webmaster Tools API key (бесплатно) — даёт независимые данные по ссылкам и индексации, а индекс Bing питает цитирования Microsoft Copilot.
