# Refactor Prompts

Two prompt series, generated from two different audits:

- **`audit-2026-ru/`** — `phase-1` … `phase-5` (Russian). Generated from the March 2026 RU audit (`docs/archive/TECHNICAL_AUDIT_2026.md`, now archived).
- **`audit-latest-en/`** — numbered `01-` … `07-` prompts (English). Generated from the canonical EN audit (`docs/TECHNICAL_AUDIT_LATEST.md`, 2026-05-31). Note: this folder contains two prompt generations with overlapping numbers (e.g. two `02-`, `03-`, `04-`, `05-` files) — the files titled "Refactor Prompt 0X — …" are one pass, the plain "# Goal" files another; both target the same audit.

The EN series supersedes the RU series where they overlap. The live backlog is maintained in the workspace at `docs/engineering/BACKLOG.md`.
