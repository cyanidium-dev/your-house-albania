# Domlivo: что делаем каждый месяц

Рутина по SEO, контенту и аналитике. Одна сессия в начале месяца (2–3 часа), плюс короткая еженедельная проверка. Всё, что помечено 👤, делает владелец; 🤖 делается кодом и скриптами в admin. Журнал результатов ведём в `docs/seo/PLAN-2026-Q4.md`, раздел «Журнал».

## Еженедельно (15 минут, понедельник)

- [ ] GSC → Эффективность → 7 дней: клики, показы, позиция. Записать три числа. Плато или падение больше 20 % при тех же показах = искать причину в тот же день.
- [ ] GSC → Эффективность → Запросы → сортировка по показам, фильтр «клики = 0»: запросы с 20+ показами и позицией до 10 без кликов. Для каждого проверить, содержит ли заголовок страницы слова запроса. Правим `seo.metaTitle` в Sanity (скрипты `patch*Title*.ts` в admin как образец).
- [ ] Clarity → Dashboard → 7 дней: сеансы, dead clicks, JS errors. Новая ошибка в консоли = открыть запись и воспроизвести.
- [ ] Vercel → последний деплой зелёный, `https://www.domlivo.com/icon.png` и `/apple-icon.png` отдают 200, `/blog/x` без языка отдаёт 308.

## Ежемесячно, 1–3 число

### 1. Срез цифр (🤖, 30 минут)

Заполнить таблицу за прошлый месяц и сравнить с предыдущим:

| Источник | Что записываем |
|---|---|
| GSC, 28 дней | клики, показы, CTR, позиция; топ-5 стран; топ-10 страниц; топ-10 запросов |
| GSC → Страницы | проиндексировано / не проиндексировано; «обнаружено, не проиндексировано»; «страница с переадресацией» |
| GSC → Файлы Sitemap | все прочитаны без ошибок; число URL в `sitemap-properties.xml` и `sitemap-properties-trimmed.xml` |
| Clarity, 30 дней | сеансы; рефереры (google, chatgpt, bing, threads); события `click_whatsapp`, `lead_submit`, `contact_form_submit` |
| Ahrefs, 1 отчёт | DR, ссылающиеся домены (сколько настоящих, не спам), «AI responses» по ChatGPT |
| Lighthouse, мобильный | главная, `/en/albania/durres`, одна карточка, одна статья: Performance, LCP, TBT, вес JS |

Lighthouse запускается локально (дефолтный кэш npm сломан):

```bash
npx --yes --cache ./lhcache lighthouse https://www.domlivo.com/sq --form-factor=mobile --screenEmulation.mobile --output=json --output-path=./lh.json --quiet --chrome-flags="--headless=new"
```

GSC и Ahrefs читаются только через Chrome владельца, API-ключей нет.

### 2. Индексация и технический контроль (🤖, 20 минут)

- [ ] Apex `https://domlivo.com/...` и пути без языка: 308 на `www` и на `/sq/...`. Проверка: `curl -sI https://domlivo.com/sq/albania/tirana/info`.
- [ ] Доля в индексе по картам сайта карточек: GSC → Страницы → выпадающий список «Все известные страницы» → выбрать карту. Сравнить полную и урезанную (эксперимент по локалям, ADR 008).
- [ ] Выборка 20 заголовков (`<title>`) по типам страниц: длина до 60 знаков, бренд один раз, без «Domlivo — Domlivo».
- [ ] `sitemap.xml` содержит все части; ни одна часть не пуста, кроме `sitemap-knowledge.xml`, пока раздел noindex.
- [ ] Новые объекты за месяц прошли генератор локализованных слагов (см. память «Per-locale property URLs»), иначе у них нет URL на 7 языках.

### 3. Контент: одна статья по первичным данным (🤖 текст, 👤 вычитка sq и pl)

Не пересказ новостей. Берём первичный источник, вынимаем цифры, добавляем свои данные по объявлениям и раздел «что это значит покупателю», ссылка на источник, 7 языков.

Календарь источников:

| Когда | Источник | Что публикуем |
|---|---|---|
| Каждый месяц | Sanity, активные объявления | Индекс цен предложения по Дурресу (скрипт `createPriceIndexArticle.ts`, образец `durres-asking-price-index-2026-09`) |
| Апрель и октябрь | Банк Албании, vrojtimi i tregut të pasurive të paluajtshme (Monitor пересказывает через 1–3 дня) | Полугодовой обзор рынка (образец `albania-property-market-h1-2026`) |
| Декабрь | ERE, тарифы на электроэнергию на следующий год | Обновить расходы на содержание в статьях и калькуляторах |
| По событию | Закон о налоге на недвижимость, референсные цены ASHK, закон об иностранцах 79/2021 | Заметка «что изменилось и что это значит при покупке» |
| Квартал | INSTAT, разрешения на строительство и сделки | Абзац в очередной статье, не отдельный текст |

Формат файлов и проверки: `scripts/data/articles-YYYY-MM-DD/<slug>.<locale>.md`, скрипт по образцу `createArticles20260930.ts` в admin. Числа в переводах должны совпадать с английским файлом, метазаголовок до 60 знаков, описание 140–160, внутренние ссылки отвечают 200 на всех языках. Файлы пишем инструментом записи, а не одной командой в консоли.

После публикации:

- [ ] IndexNow вручную: ключ из `GET /api/indexnow-key`, `POST https://api.indexnow.org/indexnow` с `host`, `key`, `keyLocation https://www.domlivo.com/indexnow-<key>.txt`, `urlList` на 7 языках.
- [ ] GSC → Проверка URL → «Запросить индексирование» для английской версии (квота небольшая, не тратить на всё подряд).
- [ ] Ссылка на новую статью из двух старых по теме (абзац в конце, как в `patchPlGuideSarandaLink20260930.ts`).

### 4. Ссылки и упоминания (👤, 2 часа в месяц)

Это единственное, что двигает DR с нуля. Цель: 3–5 настоящих ссылок в месяц.

- [ ] Каталоги агентств: Indomio.al, AlbaniaYP, Realting, Propertyhub. Одна регистрация в месяц, пока не закончатся.
- [ ] Партнёры, чьи объекты стоят на сайте: попросить ссылку с их сайта на свою страницу агента или на карточки.
- [ ] Польские и украинские сообщества (Polacy w Albanii, Nieruchomości w Albanii, Albania po polsku, Polka Inwestuje, Expat Exchange): один пост с цифрами из свежей статьи и ссылкой на таблицу цен, без рекламы.
- [ ] Threads: 2–3 поста в неделю с одной цифрой и ссылкой; это второй канал после Google.
- [ ] Проверить в Ahrefs, что спам-домены не превратились в ручные меры: GSC → Проблемы безопасности и меры, принятые вручную.

### 5. Товар (👤)

- [ ] Число активных объектов по городам: Дуррес, Саранда, Влёра, Тирана. Город с меньше чем 10 объектами не показывает счётчик на главной и не поднимается в поиске. Цель: 30 в Саранде, Влёре, Тиране.
- [ ] Фото: объекты с чужими водяными знаками снять с главной или заменить фото.
- [ ] Ушедшие с рынка объекты сняты с публикации, а не оставлены с старой ценой; история цены пишется импортом.

## Чего не делать

- Не переписывать чужие новости и не публиковать статьи без первичного источника.
- Не ставить `revalidate` ниже 3600 и не гнать Sanity-запросы в цикле: квоты Vercel.
- Не добавлять языки и города без товара.
- Не покупать ссылки и не отвечать на предложения «SEO-ферм»: все 700 спам-доменов в Ahrefs оттуда.
- Не менять заголовки страниц, которые уже приносят клики, ради формы: правим только нулевой CTR.
