# ТЗ SEO-06b — убрать пустые городские листинги из индекса

Исследование проведено 2026-08-30.

## Цель

Перестать отдавать в индекс городские страницы каталога, в которых нет ни одного объекта, и не перечислять их в sitemap. Возврат в индекс должен происходить сам, как только объекты появятся.

## Контекст исследования

**Замер на проде (30.08.2026)** — сколько объектов показывает городская страница и что говорит `robots`:

| Город | Объектов | robots |
|---|---|---|
| durres | 23 | нет → индексируется |
| sarande | 6 | нет → индексируется |
| vlore | 4 | нет → индексируется |
| shengjin | 2 | нет → индексируется |
| **tirana** | **0** | нет → **индексируется** |
| **himare** | **0** | нет → **индексируется** |
| **shkoder** | **0** | нет → **индексируется** |

Три из семи городов отдают пустой список и при этом открыты к индексации. Тирана здесь дороже всех: это и самый крупный запрос албанского ядра (`shtepi ne shitje tirane`, 3.2K GSV), и заметный английский (`real estate tirana`, 350 GSV) — а страница показывает ноль объектов.

**Почему это вредит.** Пустая страница результатов — то, что Google прямо просит не индексировать. Она не отвечает на запрос, портит поведенческие метрики и тянет вниз оценку качества всего раздела.

**Что уже есть в коде.** Порог `LISTING_DEAL_TYPE_NOINDEX_THRESHOLD = 15` применяется:
- в `[city]/[[...filters]]/page.tsx` — только когда заданы **и** `deal`, **и** `type`;
- при фильтре `?district=` — отдельным необъявленным числом `20` прямо в коде;
- в `sitemap.ts` для комбинаций deal/type.

**Голая страница города проверки количества не имеет вообще.** Это и есть пробел.

## Решение и его границы

**Порог для городского листинга — ноль, а не 15.** Страница с двумя-шестью объектами на запрос всё-таки отвечает, просто небогато; выкидывать из индекса Влёру (4), Саранду (6) и Шенджин (2) — значит потерять четыре из семи городов ради чистоты, которой никто не просил. Ноль объектов однозначен: показывать нечего. Правило узкое, обратимое и срабатывает само.

**Считать тем же запросом, которым страница строит список** (`fetchCatalogProperties` по городу, `pageSize: 1`, читаем `totalCount`). Отдельная логика подсчёта рано или поздно разойдётся с тем, что видит посетитель, и `robots` начнёт врать.

## Файлы

- `src/lib/seo/listingIndexPolicy.ts` — константы: порог пустого листинга; заодно дать имя числу `20` для района.
- `src/app/[locale]/[country]/[city]/[[...filters]]/page.tsx` — проверка в `generateMetadata`.
- `src/lib/sanity/queries/sitemap.ts` — `fetchSitemapCityEntries`: не выводить города без объектов.
- `src/lib/seo/__tests__/listingIndexPolicy.test.ts` — тесты решающей функции.

## Что можно менять

- Добавить константы и чистую функцию решения в `listingIndexPolicy.ts`.
- Считать объекты города в `generateMetadata`, когда нет ни deal, ни type, ни district.
- Отфильтровать пустые города в городском sitemap.

## Что менять нельзя

- Не менять порог 15 для deal+type и 20 для района — это отдельные решения, они работают.
- Не трогать canonical, hreflang и заголовки.
- Не скрывать страницу от людей: `noindex` — да, `follow` остаётся, страница открыта и по ссылке доступна.
- Не удалять документы городов и не выключать их в CMS.
- Не добавлять второй способ подсчёта: только `fetchCatalogProperties`.

## План

1. В `listingIndexPolicy.ts`: `EMPTY_CITY_LISTING_NOINDEX_MAX = 0`, `LISTING_DISTRICT_NOINDEX_THRESHOLD = 20` и `shouldNoindexEmptyCityListing(totalCount)`.
2. В городской странице: если нет `dealForPath`, `typeSlug` и `search.district` — запросить счётчик и применить правило.
3. Заменить в этом же файле число `20` на новую константу.
4. В `fetchSitemapCityEntries` посчитать опубликованные объекты по городам и не выводить города с нулём.
5. Тесты на чистую функцию: 0 → noindex, 1 → index, отрицательное/NaN → noindex (защита от сбоя запроса).

## Приёмка

- `/en/albania/tirana`, `/himare`, `/shkoder` отдают `<meta name="robots" content="noindex, follow">`.
- `/en/albania/durres`, `/vlore`, `/sarande`, `/shengjin` остаются без `robots` (индексируются).
- `sitemap-cities.xml` не содержит пустых городов и содержит остальные.
- Как только у города появляется объект, `noindex` пропадает без правки кода — проверяется тестом на функции.
- Число `20` для района больше не встречается литералом в странице.
