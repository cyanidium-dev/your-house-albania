### Приоритет и его обоснование

Ваша knowledge base ставит приоритет **EN > PL > RU > IT > DE > SQ**. Данные Ahrefs это подтверждают, хотя по чистому объёму албанский рынок в 6 раз больше всех остальных вместе взятых. Противоречия здесь нет:

- **SQ = много трафика, мало денег.** Головы (`shtepi ne shitje`, KD 46) держат классифайды с десятками тысяч объявлений. С 36 объектами конкурировать по инвентарю невозможно. Албанские запросы — это местные покупатели с низким чеком.
- **PL/EN/RU/IT = мало трафика, много денег.** Иностранный покупатель с чеком €80–250K. И — ключевое — **в польской выдаче первое место занимает сайт с DR 0**, в итальянской и русской KD равен нулю. Это ниши, которые никто не занял.

**Решение роадмапа:** сначала иностранные локали (Q1–Q3), албанский — в Q4 и точечно, по длинному хвосту районов, где классифайды слабы. SQ остаётся дефолтной локалью для местных, но не является точкой роста первого года.

## 1. Как пользоваться этим документом

- Каждая задача = один PR, одна ветка `feat/seo-NN-…`, по образцу существующих `docs/refactor-prompts/`.
- **Задачи для Claude** помечены 🤖 — их текст можно скармливать в Claude Code как готовое ТЗ.

- Каждая задача содержит блок **Проверка** — команда или запрос, который однозначно отвечает «сдано/не сдано».
- Обязательные проверки перед мержем любой 🤖-задачи: `npm run lint`, `npm run test`, `npm run build`.

## 7. Риски и на что смотреть

- **Каталог — главный риск.** Если SEO-07 не выполняется, страницы районов и программные лендинги упираются в гейт «≥ 3 объекта» и не публикуются. Весь Q2 зависит от наполнения.
- **Албанский без носителя.** Публиковать sq-контент без вычитки нельзя — это прямое нарушение CONTENT-OPS и риск для доверия на домашнем рынке.
- **Программные страницы.** Гейты качества из SEO-12 не смягчать: массовые тонкие страницы обвалят индексацию всего домена.
- **Ссылочный спам.** Не вернуться к закупке в тех же сетках при отсутствии быстрых результатов.
- **Данные Ahrefs по SV занижены для малых рынков.** Ориентируйтесь на GSV и на реальные показы из GSC, когда они накопятся (SEO-01).
- **KD 0 не значит «топ за неделю».** При DR 0 первые движения — 6–10 недель после публикации, устойчивые позиции — 4–6 месяцев.
